# AI OBEC 2026 — Knowledge Development Loop

GitHub เป็นแหล่งควบคุมแผนและมาตรฐานการทำงานเท่านั้น ส่วนหลักฐานต้นทางและเอกสารสังเคราะห์สำหรับใช้ภายในอยู่ใน Google Drive ที่ผู้ดูแลกำหนด ไม่เผยแพร่เอกสารภายในบน repository สาธารณะ
