# Quality Gate V1.0
- EVIDENCE: ระบุชื่อไฟล์ต้นทาง ตำแหน่งหรือหัวข้อ รุ่น/วันที่ที่ตรวจ และลิงก์ในเอกสารภายในเท่านั้น
- ACCURACY: แยกข้อเท็จจริง ข้อเสนอ และประเด็นรอยืนยัน; ตัวเลข/วันที่ขัดกันต้องแสดงทั้งสอง ไม่เลือกโดยเดา
- COMPLETENESS: ตรวจหน่วยอบรม 9 องค์ประกอบและทำรายการช่องว่าง; ห้ามเติมร่างแล้วอ้างว่าเป็นต้นฉบับ
- ACTIONABILITY: ระบุขั้นตอน เครื่องมือ ผลงาน เกณฑ์ประเมิน ผู้รับผิดชอบตามบทบาท และหลักฐานผลลัพธ์
- PRIVACY: ปกปิดข้อมูลส่วนบุคคลและข้อสอบภายในจากพื้นที่สาธารณะ; ไม่เปลี่ยนสิทธิ์การแชร์
- DELIVERY: ตรวจปลายทาง ชื่อไฟล์ MIME และอ่านกลับ; PDF ตรวจการแสดงผลเมื่อทำได้ หากตรวจไม่ได้ระบุข้อจำกัด
- IDEMPOTENCY: ใช้ทะเบียน source ID + revision; ไม่สร้างซ้ำ ไม่ทับรุ่นที่ผ่านการตรวจรับ
- REPORT: สถานะ PASS, PARTIAL, BLOCKED, NO_CHANGE และระบุ next action
