# Quality Gate V1.3
- EVIDENCE: ระบุชื่อไฟล์ต้นทาง ตำแหน่งหรือหัวข้อ รุ่น/วันที่ที่ตรวจ และลิงก์ในเอกสารภายในเท่านั้น
- ACCURACY: แยกข้อเท็จจริง ข้อเสนอ และประเด็นรอยืนยัน; ตัวเลข/วันที่ขัดกันต้องแสดงทั้งสอง ไม่เลือกโดยเดา
- COMPLETENESS: ตรวจหน่วยอบรม 9 องค์ประกอบและทำรายการช่องว่าง; ห้ามเติมร่างแล้วอ้างว่าเป็นต้นฉบับ
- ACTIONABILITY: ระบุขั้นตอน เครื่องมือ ผลงาน เกณฑ์ประเมิน ผู้รับผิดชอบตามบทบาท และหลักฐานผลลัพธ์
- PRIVACY: ปกปิดข้อมูลส่วนบุคคลและข้อสอบภายในจากพื้นที่สาธารณะ; ไม่เปลี่ยนสิทธิ์การแชร์
- DELIVERY: PDF ผลผลิตทุกฉบับต้องเก็บใน Drive ปลายทางตามหมวดงาน ตรวจชื่อซ้ำ ชื่อไฟล์ MIME รูปแบบการแสดงผล และอ่านกลับจาก Drive พร้อมยืนยันลิงก์จริงในรายงานและ log; ไฟล์แนบแชทหรือ sandbox ไม่ใช่หลักฐานส่งมอบแทน Drive หากอัปโหลดหรืออ่านกลับไม่ได้ห้ามให้ PASS และระบุงานส่งมอบค้างไว้
- IDEMPOTENCY: ใช้ทะเบียน source ID + revision; ไม่สร้างซ้ำ ไม่ทับรุ่นที่ผ่านการตรวจรับ
- REPORT: สถานะ PASS, PARTIAL, BLOCKED, NO_CHANGE และระบุ next action

## V1.3 — สื่อสองแบบต่อหัวข้อ
ทุกหัวข้อสื่อ (panel_id) ต้องสร้าง Infographic A4 อย่างน้อย 2 แบบ (A/B) ใช้สาระและข้อความหลักจาก JSON/MD เดียวกัน แต่ต่างกันชัดเจนด้านองค์ประกอบภาพและการจัดวาง ตรวจ QA แยกแต่ละแบบ อัปโหลดทั้งสองแบบที่ผ่าน QA เข้า Drive ปลายทางทันทีโดยไม่ต้องรอผู้ใช้เลือก ตั้งชื่อ YYYY-MM-DD_topic_vNN_infographic_NN_A.png และ _B.png (เพิ่มเติม C เป็นต้นเมื่อจำเป็น) บันทึก variant_id, QA, ลิงก์ Drive และสถานะการเลือกใน log; ผู้ใช้เลือกภายหลังได้ เก็บทั้งสองแบบ ไม่ลบหรือทับรุ่นเดิม หากแบบใดไม่ผ่านให้แก้หรือระบุ PARTIAL ไม่ถือว่าส่งมอบครบ และไม่เปลี่ยนเวลา automation หรือผลิต PDF ซ้ำ
