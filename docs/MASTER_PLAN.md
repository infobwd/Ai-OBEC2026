# Master Plan V1.0
## เป้าหมาย
เปลี่ยนคลังเอกสารให้เป็นองค์ความรู้ที่ค้นได้ ตรวจสอบย้อนกลับได้ และนำไปใช้จริงในการอบรมครูและการบริหารโรงเรียน โดยไม่แทนที่เอกสารราชการต้นฉบับ

## แผนงาน
| ระยะ | ผลส่งมอบ | เกณฑ์จบ |
|---|---|---|
| P0 | สำรวจทะเบียนไฟล์และจัดเก็บต้นฉบับสำเนา | ระบุไฟล์ต้นทาง/สำเนา รุ่น สถานะการอ่าน และรายการซ้ำ |
| P1 | สังเคราะห์เป้าหมาย หลักสูตรและกรอบสมรรถนะ | แยกข้อความต้นฉบับ ข้อเสนอ ช่องว่าง และประเด็นรอยืนยัน |
| P2 | คู่มือรายโดเมน 1–6 | อย่างน้อยหนึ่งชุดต่อโดเมน มีวัตถุประสงค์ กิจกรรม ใบงาน เกณฑ์ประเมินและหลักฐาน |
| P3 | แนวทางพัฒนาครูแกนนำ ครูทั่วไป และการรับรองสมรรถนะ | เปรียบเทียบสองกลุ่มเป้าหมาย เชื่อมหลักสูตรกับการประเมินและขยายผล |
| P4 | แนวทาง Sandbox และ PLC | มีแผนทดลอง ปรับปรุง ติดตามผลผู้เรียน/งานครู และมาตรการคุ้มครองข้อมูล |
| P5 | ดูแลความทันสมัย | ตรวจการเปลี่ยนแปลงรายวัน ไม่สร้างเอกสารซ้ำ และรักษาประวัติรุ่น |

## ลำดับความสำคัญ
1. ทำทะเบียนและวิเคราะห์เอกสารหลักก่อน
2. สังเคราะห์รายโดเมนตามลำดับ โดยเริ่มจากความฉลาดรู้และความปลอดภัย แล้วจึงพัฒนาวิชาชีพ การสอน วิจัย และบริหาร
3. สังเคราะห์การรับรองและการขยายผล
4. สร้างเครื่องมือปฏิบัติที่ทดลองได้ เช่น checklist, rubric, lesson design, dashboard blueprint และ PLC protocol
5. ตรวจสอบกับหลักฐานก่อนนำไปใช้ ไม่อ้างว่าเป็นข้อบังคับโดยไม่มีประกาศยืนยัน
