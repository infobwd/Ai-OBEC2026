## แหล่งข้อมูลและการใช้หลักฐาน
Google Drive ต้นทาง “AI สพฐ. 2026” อ่านอย่างเดียว; ปลายทาง “DOC” และหมวด “08 แนวทางปฏิบัติและองค์ความรู้ (AI Loop)” เก็บผลผลิตภายใน ใช้บัญชีและโฟลเดอร์ที่กำหนดในบริบทโปรเจกต์หรือการตั้งค่า Loop เท่านั้น ไม่ค้นหาโฟลเดอร์ชื่อซ้ำแทนโดยพลการ
อ่านต้นฉบับที่เกี่ยวข้องจริง ระบุชื่อไฟล์ รุ่น/วันที่ หน้า/หัวข้อ และลิงก์ภายในเมื่ออนุญาต แยกข้อเท็จจริง ข้อเสนอ และประเด็นรอยืนยัน ตรวจภาพ ตาราง ข้อความขีดฆ่าและการแก้ไขในเอกสาร ไม่ใช้ข้อความสกัดอย่างเดียวเพื่อยืนยันเนื้อหาฉบับแก้ไข หากตรวจไม่ได้ให้ระบุข้อจำกัด หากค้นคว้าเพิ่มเติมให้ใช้แหล่งทางการ งานวิจัย หรือคู่มือผู้พัฒนา ตรวจวันที่และอ้างอิงแยกจากหลักฐานภายใน

## ขอบเขตวิชาการ
กรอบ 6 โดเมน: 1 ความรู้ ความเข้าใจและความฉลาดรู้ AI; 2 จริยธรรม กฎหมายและความปลอดภัย; 3 การเรียนรู้ตลอดชีวิต การปรับตัวและพัฒนาวิชาชีพ; 4 การจัดการเรียนรู้และพัฒนาผู้เรียน; 5 วิจัย นวัตกรรมและสร้างองค์ความรู้; 6 บริหารจัดการ ขับเคลื่อนองค์กรและสร้างเครือข่าย
ศึกษาหลักสูตรแกนนำและครูทั่วไปแยกกัน Certificate เป็นกลุ่มงาน ไม่ใช่โดเมนที่ 7 ตรวจหลักฐานล่าสุดก่อนกำหนดเวลา เนื้อหา เครื่องมือ และเกณฑ์รับรอง
หน่วยอบรมมี 9 องค์ประกอบ: ชื่อหน่วยและเวลา สาระสำคัญ วัตถุประสงค์ ขอบข่ายเนื้อหา กิจกรรม (นำเข้า–ให้ความรู้–ฝึกปฏิบัติ–สะท้อนคิด/สรุป) ใบความรู้ ใบงาน สื่อประกอบ และประเมินผลประจำหน่วย
เน้น Active Learning การฝึกจริง ผลงานที่ตรวจรับได้ ความเหมาะสมกับบริบทโรงเรียนและช่วงวัย PLC การขยายผล และผลลัพธ์ผู้เรียน ไม่ผูกกับผู้ให้บริการ AI รายเดียว

## วิธีทำงาน
- “วิเคราะห์/วางแผน” ให้เสนอผลโดยไม่แก้ระบบหรือเผยแพร่; “ดำเนินการ/ทำงานต่อ/เดิน Loop” ให้ลงมือจริงตามขอบเขตและสิทธิ์
- เลือกงานจากแผนและ backlog ล่าสุด อ่านหลักฐาน ผลิตงาน ตรวจ QA บันทึกผลและงานถัดไป
- Knowledge Loop ทำหนึ่งชุดต่อรอบ ตรวจต้นทางทุกโฟลเดอร์และทุกหน้า เทียบ source ID + revision/modified time กับทะเบียน ตรวจสำเนาก่อนเขียน ไม่สร้างซ้ำ ไม่ลบต้นทาง ไม่ทับรุ่นเดิม หากอ่านทะเบียนไม่ได้ห้ามคัดลอกซ้ำ
- งานสังเคราะห์มีหลักฐาน ข้อจำกัด ขั้นตอนปฏิบัติ เครื่องมือ ผลงาน เกณฑ์ประเมิน ผู้รับผิดชอบตามบทบาท ความเสี่ยง และประเด็นรอยืนยัน
- บันทึกทะเบียน backlog และ log ใน Drive ภายใน อัปเดตสถานะภาพรวมใน GitHub เฉพาะเมื่อมีความเปลี่ยนแปลง

## การส่งมอบ PDF (บังคับ)
PDF ผลผลิตทุกฉบับ ทั้งจากแชทปกติและ Knowledge Loop ต้องอัปโหลดไปยัง Google Drive ปลายทางตามหมวดงาน ตั้งชื่อ YYYY-MM-DD_topic_vNN ตรวจชื่อซ้ำก่อนอัปโหลด รักษารุ่นเดิม ตรวจการแสดงผล ชื่อไฟล์ MIME โฟลเดอร์ อ่านกลับจาก Drive และยืนยันลิงก์จริง บันทึกลิงก์ใน log/ทะเบียนผลผลิต และส่งลิงก์ Drive ให้ผู้ใช้ทุกครั้ง
ไฟล์แนบแชทหรือ sandbox ไม่ใช่การส่งมอบแทน Drive หากอัปโหลดหรืออ่านกลับไม่ได้ห้ามรายงาน PASS ให้ระบุ PARTIAL/BLOCKED และบันทึกงานส่งมอบค้างไว้ หากไม่มีงานหรือความเปลี่ยนแปลงจริงไม่สร้างไฟล์ซ้ำ

## ความปลอดภัยและ QA
ใช้ Human-in-the-loop ตรวจความถูกต้อง อคติ ลิขสิทธิ์ PDPA และเงื่อนไขการใช้ AI ตามวัย ใช้ข้อมูลจำลอง/ไม่ระบุตัวตน ไม่ส่งข้อมูลผู้เรียนหรือข้อมูลภายในไปยังบริการที่ไม่ได้รับอนุญาต ไม่เปลี่ยนสิทธิ์แชร์ ไม่ใช้บริการเสียเงินโดยไม่ได้รับอนุญาต
GitHub สาธารณะเก็บเฉพาะแผน มาตรฐาน แม่แบบทั่วไป และสถานะภาพรวม ห้ามเผยแพร่เอกสารภายใน ข้อสอบ รายชื่อ อีเมล ลิงก์ Drive ภายใน หรือข้อมูลลับ
ตรวจตาม QA_STANDARD.md รายงาน PASS / PARTIAL / BLOCKED / NO_CHANGE ตามผลจริง ห้ามสร้างหลักฐานเทียม ห้ามอ้างว่าส่งมอบแล้วหากยังไม่ตรวจสอบ
