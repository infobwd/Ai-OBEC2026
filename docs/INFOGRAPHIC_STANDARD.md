# Infographic Production Standard V1.4
## ขอบเขต
ผลผลิตองค์ความรู้ใหม่/ฉบับปรับปรุงจากแชทและ Knowledge Loop ทุกชุด; งานทะเบียนหรือธุรการที่ไม่มีสาระสำหรับภาพระบุ N/A ใน log
## ขั้นตอน
1. PDF ผ่าน QA และส่งมอบ Drive ตามมาตรฐานเดิมก่อน
2. สร้าง JSON (หลัก) หรือ Markdown (ทางเลือก) จาก PDF ที่ตรวจแล้ว: work_id, source_version, revision, audience, status, panels[]; แต่ละ panel มี id, title, takeaway, exact_text, visual_brief, source_refs, claim_status; แยกข้อเท็จจริง ข้อเสนอ รอยืนยัน
3. Repo สาธารณะเก็บ schema/แม่แบบและเนื้อหาความรู้ทั่วไปที่ได้รับอนุญาตให้เผยแพร่เท่านั้น; JSON/MD ฉบับเต็มและหลักฐานภายในเก็บ Drive ห้ามเผยแพร่ข้อมูลบุคคล ข้อสอบ URL/ID ภายใน ไม่เปลี่ยนสิทธิ์แชร์
4. ผลิตภาพ A4 แนวตั้ง 210×297 มม. เป้าหมาย PNG 2480×3508 px ที่ 300 dpi หรือขนาดพิมพ์เทียบเท่า; หนึ่งภาพหนึ่งประเด็น จำนวนตามสาระ ไม่อัดข้อความ ธีมน้ำเงินเข้ม/ฟ้าอมเขียว/ทองอ่อน พื้นสว่าง ตัวอักษรไทยอ่านง่าย มีรหัสงาน เลขภาพ รุ่น และสถานะสื่อ ไม่ใช้ตราทางราชการโดยพลการ
5. ตรวจภาษาไทยทุกบรรทัด ความถูกต้อง ตัวเลข ความสอดคล้องกับ JSON/PDF ลิขสิทธิ์ ความเป็นส่วนตัว ขอบตัด ความละเอียดและสัดส่วน A4; หากภาพ AI สะกดผิด ให้แก้หรือจัดวางตัวอักษรด้วยเครื่องมือที่เหมาะสมก่อนตรวจรับ
6. เก็บ JSON/MD และ PNG ทุกภาพใน Drive ปลายทางหมวดงานเดิม ตั้งชื่อ YYYY-MM-DD_topic_vNN_infographic_NN.png; ตรวจชื่อซ้ำ MIME โฟลเดอร์ อ่านกลับและลิงก์; PDF รวมภาพถ้ามีใช้กฎ PDF เดิม
7. บันทึก source_version + media_revision + panel_id จำนวนภาพ ลิงก์ภายใน QA และ media_status ใน log/backlog; งานใหม่ PASS เมื่อผลผลิตที่เกี่ยวข้องผ่านครบ หากสื่อค้างให้ PARTIAL ไม่ผลิต PDF ซ้ำถ้าเนื้อหาไม่เปลี่ยน
## เปลี่ยนผ่าน
D1 PDF เดิมยัง DONE_INTERNAL; ทดลองสื่อหนึ่งภาพก่อน เติมชุดเต็ม D1/P1 ผ่านคิวสื่อแยกโดยไม่ย้อนสถานะ PDF และไม่เปลี่ยน D2 ซึ่งเป็นงานถัดไปสายวิชาการ; รักษาหนึ่งชุดต่อรอบเดิม หากเครื่องมือสร้างภาพหรืออัปโหลดไม่พร้อม บันทึก MEDIA_PENDING ไม่รายงานส่งมอบแล้ว ไม่ใช้บริการเสียเงินเพิ่มหรือสร้าง automation ใหม่

## V1.3 — สื่อสองแบบต่อหัวข้อ
ทุกหัวข้อสื่อ (panel_id) ต้องสร้าง Infographic A4 อย่างน้อย 2 แบบ (A/B) ใช้สาระและข้อความหลักจาก JSON/MD เดียวกัน แต่ต่างกันชัดเจนด้านองค์ประกอบภาพและการจัดวาง ตรวจ QA แยกแต่ละแบบ อัปโหลดทั้งสองแบบที่ผ่าน QA เข้า Drive ปลายทางทันทีโดยไม่ต้องรอผู้ใช้เลือก ตั้งชื่อ YYYY-MM-DD_topic_vNN_infographic_NN_A.png และ _B.png (เพิ่มเติม C เป็นต้นเมื่อจำเป็น) บันทึก variant_id, QA, ลิงก์ Drive และสถานะการเลือกใน log; ผู้ใช้เลือกภายหลังได้ เก็บทั้งสองแบบ ไม่ลบหรือทับรุ่นเดิม หากแบบใดไม่ผ่านให้แก้หรือระบุ PARTIAL ไม่ถือว่าส่งมอบครบ และไม่เปลี่ยนเวลา automation หรือผลิต PDF ซ้ำ

## V1.4 — สื่อ A4 และ 1:1 (27 พฤศจิกายน 2569)
ขยาย V1.3: ทุก panel_id ที่เหมาะสำหรับสื่อ ให้ผลิต A4 แนวตั้ง A/B และสี่เหลี่ยม 1:1 A/B (รวมอย่างน้อย 4 ภาพต่อหัวข้อ) จาก JSON/MD เดียวกัน ปรับการจัดวางตามสัดส่วน ไม่ครอปจนเนื้อหาหาย; 1:1 เป้าหมายอย่างน้อย 1080×1080 px สำหรับมือถือ/สื่อออนไลน์ ส่วน A4 คงเกณฑ์พิมพ์ 2480×3508 px ที่ 300 dpi หรือเทียบเท่า. ใช้ธีมร่วม แบบ A การ์ตูนให้ความรู้ แบบ B วิชาการสมัยใหม่. เพิ่ม aspect_ratio, variant_id, panel_id, source_version, media_revision, dimensions, QA และ delivery_status ในทะเบียน; ตั้งชื่อ YYYY-MM-DD_topic_vNN_infographic_NN_A4_A.png / _A4_B.png / _SQ_A.png / _SQ_B.png. เก็บไฟล์เดิมและนับ A4 เดิมที่ตรวจแล้วโดยไม่ผลิตซ้ำ; แบ่งชุดสร้างตามขีดจำกัดเครื่องมือ ไม่รับประกัน 10 ภาพต่อคำขอ ไม่ใช้บริการเสียเงินเพิ่ม. ตรวจข้อความไทย ความถูกต้อง การอ่านบนมือถือ ขนาดจริง สิทธิ์ และอ่านกลับจาก Drive แยกทุกภาพ; เก็บ A4 และ 1:1 แยกหมวดหรือแยกด้วยชื่อไฟล์ในหมวดงานเดิม ไม่เปลี่ยนสิทธิ์แชร์. หากเครื่องมือไม่พร้อมหรือภาพไม่ถึงเกณฑ์ ให้บันทึก PARTIAL/MEDIA_PENDING และเติมคิวสื่อภายหลังโดยไม่ผลิต PDF ซ้ำหรือเปลี่ยนคิววิชาการ D2/เวลา automation เดิม. การเผยแพร่ภายนอกต้องได้รับอนุญาต.
